API token setup

In Proxmox, go to Datacenter → Permissions → API Tokens → Add. Select a user (a dedicated non-root account with the PVEAuditor role is recommended over root@pam), enter any label as the Token ID, and leave Privilege Separation checked so the token starts with no permissions of its own.

After saving, Proxmox shows a combined Token ID in the form user@realm!tokenid (for example root@pam!inkypi) and a Secret — both shown only once. Copy the full combined Token ID into InkyPi's PROXMOX_TOKEN_ID key and the Secret into PROXMOX_TOKEN_SECRET, using the key icon on the main screen.

If Privilege Separation was left unchecked on a root token, that token has full admin access to your Proxmox host. Under Permissions → Add → API Token Permission, grant this token only the PVEAuditor role on path / so it can read status but not modify anything.
