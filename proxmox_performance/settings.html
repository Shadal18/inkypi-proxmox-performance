🖥 Proxmox performance

Show live VM, container, and node health from your Proxmox cluster.

Connect InkyPi to Proxmox VE to render node health, guest running states, and selected CPU and memory details on your e-paper display.

🔑

API token setup

In Proxmox, create an API token at Datacenter → Permissions → API Tokens. Save the full token ID as PROXMOX_TOKEN_ID and its secret as PROXMOX_TOKEN_SECRET in InkyPi’s API Keys page using the key icon.

Grant the token read-only access with PVEAuditor on path / and enable propagation. A dedicated non-root API user is recommended.

🔌

Proxmox connection

Enter the server address InkyPi should query.

Use the reachable Proxmox VE URL, including port 8006.

Disable only when using a self-signed certificate that InkyPi does not trust.

📊

Display settings

Control which guests appear and how much detail is shown.

Hide inactive guests to keep the display focused on running workloads.

Adds CPU percentage and memory-used details beneath running guests.
